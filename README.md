# Bike-Sharing-Demand-Analysis
Bike Share Demand Analysis Using Excel, Power Query, Excel Formulas, Pivot Table, Kpi's, Dashboard, Descriptive Statistics, Correlation Analysis, Forecasting Analysis and  Anomaly Detection.

## Datasets
- Dataset 1: Bike-sharing rental and time-related records.
- Dataset 2: Weather data, including temperature, humidity, and wind speed.
- Dataset 3: Additional bike-sharing records.

## Data Integration & Cleaning
- Merged Dataset 1 and Dataset 2 using Power Query.
- Appended Dataset 3 to create the final dataset.
- Handled missing values and checked duplicates.
- Corrected data types.

- ## Tools & Techniques
- Microsoft Excel and Power Query
- PivotTables, PivotCharts and Excel Formulas
- KPI Dashboard with Interactive Slicers and Timeline
- Descriptive Statistics and Correlation Analysis
- Forecasting and Anomaly Detection
